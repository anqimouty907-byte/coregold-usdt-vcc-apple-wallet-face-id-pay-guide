### 📱 第一步：准备好你的美区 Apple 账号与设备

1. 确保你的 iPhone 或 Mac 登录的是苹果设备（建议美区账号，兼容性最好）。
2. 打开自带的 **Apple Wallet（钱包）** App。
3. 点击右上角的 **`+`** 号，选择**“添加支付卡”**。

---

### 🔢 第二步：录入 CoreGold 虚拟卡信息

1. 不要用相机扫卡（因为虚拟卡没有实体），选择**“手动输入卡片详细信息”**。
2. 回到 [CoreGold 用户后台](https://app.coregold.io/signup?invite_code=ADvlj9b)，进入 **「卡片管理」**，把你的 16 位卡号、有效期（MM/YY）和 CVV 安全码复制过来，填进苹果钱包。

---

### 📬 第三步：关键的“邮箱验证码”怎么拿？

苹果钱包为了安全，会要求你进行身份验证：
1. 钱包提示时，选择**“通过电子邮件接收验证码（Email Verification）”**。
2. **重点来啦**：不要傻乎乎去自己的邮箱刷新！直接切回 CoreGold 后台，找到这张卡片的详情页。
3. 点击页面最下方的 **「添加到数字钱包」** 按钮，CoreGold 的系统会自动把苹果发给你的动态验证码实时显示在后台页面上。
4. 把验证码复制过去，回填到苹果钱包里。

---
